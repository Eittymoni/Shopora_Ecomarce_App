# 🛍️ Shopora — E-Commerce Android App

**Shopora** is a modern Android e-commerce application built with **Kotlin and Jetpack Compose**. It is designed to provide a smooth, user-friendly shopping experience with a clean interface, colorful product cards, and intuitive navigation.

## 🚀 Getting Started

### Prerequisites

* Android Studio
* Android SDK
* JDK version compatible with your project's Gradle configuration
* Git

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project in Android Studio.

3. Allow Gradle to sync and download the required dependencies.

4. Connect an Android device or start an emulator.

5. Click **Run ▶** to build and launch the application.
